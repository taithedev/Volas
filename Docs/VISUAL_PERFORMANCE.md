# Visual performance and player markers

Player ESP boxes and distance labels are available from Visuals in recognized MODDED multiplayer rooms only. They disappear outside such rooms and skip rigs whose remote ownership cannot be established. Box lines use a depth-tested shader; no game renderer, network state or anti-cheat is changed. Settings > Player ESP adjusts range, marker cap, refresh rate and line width. Marker objects are reused, scene scans run once per 1.25 seconds only while enabled, and room eligibility is checked continuously. Reflection member lookup and hand transforms are cached. Disabled local visuals skip unnecessary tracking work, and owned materials are released. No measured FPS or in-game compatibility claim is made; test with installed Unity/BepInEx assemblies.
