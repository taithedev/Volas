# Wrist interface

Default world size: 24 x 32 cm. Four rows per page, world-space Canvas with readable runtime fonts, high-contrast state colors, synchronized touch and pointer coordinates, and reusable controls. Y toggles the menu; F7 tests it. F6 > Settings > Wrist Menu Settings changes size, text, offsets, pointer visibility and feedback. An original implementation, not a copy of the provided third-party source. Requires local build and headset testing.
